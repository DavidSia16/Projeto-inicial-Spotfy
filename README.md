Projeto Inicial - Spotify (Clone)
Este projeto é uma página inicial inspirada na interface do Spotify, desenvolvida com o objetivo de praticar e aprimorar habilidades de estruturação HTML e estilização CSS.

🚀 Sobre o Projeto
O objetivo desta aplicação é recriar o layout clássico da barra lateral e da tela principal de navegação do Spotify, focando em uma experiência de usuário responsiva e limpa.

🛠️ Tecnologias Utilizadas
HTML5: Estruturação semântica das tags e dos elementos da interface.

CSS3: Estilização visual, organização de layouts (Flexbox/Grid) e separação de regras em arquivos dedicados.
